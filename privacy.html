プライバシーポリシー

最終更新：2026年9月30日

Luna-Tool（以下「本アプリ」）は、個人が自分のパソコンで使うためのアプリです。本アプリが Google のデータをどう扱うかを説明します。

使うデータ

  • Google カレンダーの予定（題名・日時・繰り返し・説明）と、カレンダーの一覧
  • ログインしたアカウントのメールアドレス（どのアカウントでつないでいるかを表示するため）

使いみち

  • 利用者の予定についての問いに答え、予定を前もって知らせるため
  • 利用者が頼み、確認した予定を、カレンダーに足す・変える・取り消すため

これ以外の目的には使いません。広告には使いません。

保存と共有

  • 予定の写しとログインの鍵は、利用者のパソコンの中だけに保存します。ログインの鍵は Windows の仕組みで暗号化して保管します。
  • Google から受け取ったデータを、第三者に売ったり渡したりしません。本アプリの開発者のサーバーにも送りません。
  • 本アプリによる Google API から受け取った情報の利用と他のアプリへの転送は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

つなぎを切る・消す

本アプリの設定画面の「つなぎを切る」で、Google への許可を取り消せます。また、Google アカウントの「サードパーティ アプリとサービス」からも取り消せます。パソコンの中の写しは、本アプリの予定の画面から取り消しの印を付けられます。

Privacy Policy (English)

Luna-Tool is a personal desktop app. It accesses the user's Google Calendar events and calendar list, and the signed-in account's email address, only to answer the user's schedule questions, send reminders, and add, change or cancel events the user has requested and confirmed. Data is stored only on the user's own computer (sign-in tokens encrypted with Windows DPAPI). It is never sold, shared with third parties, sent to the developer's servers, or used for advertising. Luna-Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked from the app's settings or from Google Account permissions.
