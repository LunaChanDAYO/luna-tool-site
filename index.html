Luna-Tool

Luna-Tool は、個人が自分の Windows パソコンで使うデスクトップアプリです。手元で動く会話用の AI「るな」と話しながら、予定の管理や作業ができます。一般には配布していません。

Google カレンダーとの連携

利用者本人が許可したときだけ、Google Calendar API を使って、利用者のカレンダーの予定を読み書きします。

  • 予定を読む：「明日の予定は？」などの問いに答えるため、また予定を前もって知らせるため
  • 予定を書く：利用者が頼み、確認したうえで、予定を足す・変える・取り消すため

データの扱いは プライバシーポリシー をご覧ください。

About (English)

Luna-Tool is a personal desktop app for Windows, used only by its owner. With the user's permission it reads and writes events in the user's Google Calendar to answer questions about the schedule, send reminders, and add, change or cancel events the user has asked for and confirmed. See the Privacy Policy.
